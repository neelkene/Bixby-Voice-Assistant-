Bixby Voice Assistant - Advanced AI Powered Personal Assistant
Project Overview
Bixby is a custom-built, wake-word activated voice assistant developed in Python, designed as
a comprehensive personal productivity tool. Activated by the wake word "Bixby," it processes
natural language commands through speech recognition and delivers intelligent responses using
cutting-edge AI integration. This project demonstrates full-stack development skills including
speech processing, API integration, system automation, and modular architecture.
Tech Stack
Core: Python 3.x, SpeechRecognition Google STT, gTTS Google TTS, pygame
AI: OpenRouter API (deepseek/deepseek-chat model) for intelligent explanations
System Control: Custom system_control module Windows automation
Additional: Requests, webbrowser, regex parsing, VoiceTranslator module
Audio: Real-time microphone processing with ambient noise cancellation
